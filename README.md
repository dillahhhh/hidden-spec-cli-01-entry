mend is one command-line patch tool for every AI edit format: unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON text-editor tool calls. It finds the lines each edit names at the first of three matching tiers (exact, trailing whitespace, full whitespace), re-indents replacement lines at the deepest tier, and changes every file or none — all or nothing, with `--check` for a dry run and `--strict` for exact matching only.

## Run it

```sh
node main.ts patch.diff
```
